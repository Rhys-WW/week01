## 重点：day5.py 猜数字游戏 v2

这是目前最完整的一个程序，实现了：

- 三档难度选择（1-10 / 1-50 / 1-100，对应 3/5/7 次机会）
- 输入校验：非数字、超出范围都不崩溃，且不消耗次数
- 剩余次数提示、猜大猜小提示
- 结算显示用了多少次猜中，并公布答案
- 重玩机制

结构上是三层嵌套循环：外层重玩 → 中层次数 → 内层输入校验。
